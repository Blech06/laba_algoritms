## Описание

Реализован шаблонный класс `Vector<T>` — упрощённый аналог `std::vector` с полной поддержкой **правила пяти**:

- Деструктор
- Конструктор копирования
- Оператор присваивания копированием
- Конструктор перемещения
- Оператор присваивания перемещением

### Основной функционал

| Метод              | Описание                              | Сложность      |
|--------------------|---------------------------------------|----------------|
| `push_back`        | Добавление в конец                    | O(1) аморт.    |
| `pop_back`         | Удаление последнего элемента          | O(1)           |
| `operator[]`       | Доступ по индексу                     | O(1)           |
| `size` / `capacity`| Размер и ёмкость                      | O(1)           |
| `reserve`          | Резервирование памяти                 | O(n)           |
| `resize`           | Изменение размера                     | O(n)           |
| `clear`            | Очистка                               | O(1)           |
| **`min()`**        | Минимальный элемент (**вариант 4**)   | **O(n)**       |
| **`max()`**        | Максимальный элемент (**вариант 4**)  | **O(n)**       |

## Особенности реализации

- Стратегия удвоения ёмкости → амортизированная сложность `push_back` = **O(1)**
- Глубокое копирование в конструкторе копирования
- Copy-and-swap idiom в операторе присваивания
- Защита от самоприсваивания
- Корректная обработка исключений (`out_of_range`, `underflow_error`, `runtime_error`)
- Поддержка range-based for через `begin()` / `end()`
